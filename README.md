# Interactive Data Visualization Project

This project focuses on data analysis and interactive data visualization using Python and Plotly.

## Technologies Used
- Python
- Pandas
- Plotly Express
- Jupyter Notebook

## Project Features
- Data cleaning and preprocessing
- Interactive visualizations
- Trend analysis
- Dashboard-style charts

## Files
- `data_visualization.ipynb` → Main Jupyter Notebook
- `dashboard.html` → Exported interactive dashboard

## Skills Demonstrated
- Data Visualization
- Data Analysis
- Exploratory Data Analysis (EDA)
- Dashboard Development
